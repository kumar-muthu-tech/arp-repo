# AeroPlanetaAI Blog (Astro + MDX + Tailwind + TypeScript)

Quick start:

1. Install dependencies:

```bash
pnpm install
# or npm install
```

2. Run dev server:

```bash
pnpm dev
```

This scaffold includes:
- Astro with MDX integration
- Shiki syntax highlighting (github-dark)
- KaTeX (rehype-katex) for math
- Tailwind CSS with `@tailwindcss/typography`
- Content collection schema in `src/content/config.ts`
